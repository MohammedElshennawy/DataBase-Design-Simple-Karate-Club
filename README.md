# 🥋 Karate Club Database

A relational database design for a Karate Club Management System that manages members, instructors, memberships, belt rank tests, payments, and training records.

The project was designed using **ERD (Entity Relationship Diagram)** and **Relational Schema** principles, with a focus on modeling complex relationships, enforcing business rules, maintaining data integrity, and supporting member progression throughout their karate journey.

## 🚀 Features

* Member Management
* Instructor Management
* Membership & Subscription Tracking
* Belt Rank Testing System
* Belt Progression History
* Membership & Test Payment Management

## 🧠 Concepts Practiced

* Database Design
* ERD Modeling
* Relational Schema Design
* Primary & Foreign Keys
* One-to-Many and Many-to-Many Relationships
* Database Normalization
* Business Requirements Analysis
* Business Rules Implementation

## 🛠️ Tools & Technologies

* SQL Database Design
* ERD Modeling
* Relational Database Concepts

This project was built as part of my database design and SQL learning journey, focusing on transforming real-world business requirements into a structured, scalable, and maintainable relational database design.
